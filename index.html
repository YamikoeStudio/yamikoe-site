О приложении

Yamikoe Studio — это десктопное приложение для удобного просмотра аниме с озвучкой нашей студии. Мы используем современные технологии для обеспечения высокого качества видео и звука.

Для доступа к видеофайлам приложение использует официальный Google Drive API (только для чтения). Мы не собираем ваши личные данные и не передаем их третьим лицам.
